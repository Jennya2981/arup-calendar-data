# Календарь задач ARUP — рабочий календарь команды

Приватный репозиторий: здесь вместе находятся приложение календаря и реальные данные команды.
Доступ только у владельца и приглашённых коллег.

## Состав

- `index.html`, `css/`, `js/` — приложение «Календарь задач» без сборки и бэкенда.
- `calendar.json` — рабочие данные: ответственные, задачи, справочники, пользователи.
- `js/config.js` — указывает на этот же репозиторий (`repo: 'arup-calendar-data'`).

## Запуск

Откройте `index.html` напрямую или через локальный сервер (`npx serve .`).

Чтобы читать и записывать `calendar.json` через GitHub API, владелец вводит ключ доступа
кнопкой «Войти как администратор». Ключ хранится только в браузере, в код не попадает.

## Важно

Репозиторий приватный. Публичный GitHub Pages не может прочитать его данные без авторизации,
поэтому ссылка на развёрнутый сайт не даёт доступа к реальным задачам. Для просмотра коллегам
нужен доступ к этому репозиторию и авторизованный вход в приложение.
