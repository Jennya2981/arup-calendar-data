# Календарь задач ARUP — рабочий календарь команды

Приложение и реальные данные команды находятся в одном репозитории.

**ВРЕМЕННО:** репозиторий открыт, чтобы коллеги могли просматривать календарь без GitHub.
После переноса на ваш хостинг доступ нужно вернуть в приватный режим.

## Как входят коллеги

GitHub-аккаунт не нужен. В боковой панели кнопки **«Регистрация»** и
**«Войти по логин+пароль»** — как и раньше. Старые регистрации из браузера
подхватываются автоматически.

## Как входит администратор

**«Войти как администратор»** → API-ключ с правом `Contents: Read and write`
на этот репозиторий. Ключ хранится только в браузере.

## Как читаются данные

Сайт на GitHub Pages берёт `calendar.json` из этого же репозитория.
Администратор с ключом редактирует через GitHub API.

## Состав

- `index.html`, `css/`, `js/` — приложение без сборки и бэкенда.
- `calendar.json` — рабочие данные: ответственные, задачи, справочники.
- `js/config.js` — `staticFile: 'calendar.json'`, `legacyKeys: true`.
