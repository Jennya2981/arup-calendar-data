# Календарь задач ARUP — рабочий календарь команды

Приватный репозиторий: приложение и реальные данные команды находятся вместе.

## Как входят коллеги

Никаких GitHub-аккаунтов не нужно. В боковой панели есть кнопки **«Регистрация»**
и **«Войти по логин+пароль»** — как и раньше. Коллеги вводят свою почту/логин и пароль;
 Данные хранятся в их браузере и подхватываются при первом открытии обновлённого сайта.

## Как входит администратор

Администратор открывает сайт и нажимает **«Войти как администратор»**, вводит API-ключ
с правом `Contents: Read and write` на этот репозиторий. Ключ хранится только в браузере.

## Как читаются данные

Сайт публикуется через GitHub Pages и берёт `calendar.json` из того же репозитория,
поэтому зрители не проходят проверку GitHub. Администратор с ключом работает через GitHub API.

## Состав

- `index.html`, `css/`, `js/` — приложение без сборки и бэкенда.
- `calendar.json` — рабочие данные: ответственные, задачи, справочники.
- `js/config.js` — `staticFile: 'calendar.json'`, `legacyKeys: true`.
